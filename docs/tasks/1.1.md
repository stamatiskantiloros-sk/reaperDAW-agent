# 1.1 — Fake bridge, op simulation, diff engine, plan store/apply flow
Goal: a pure-Python, in-memory implementation of every op so plans can be built, applied, verified and undone in unit tests without REAPER. Later the Lua `agent.apply_plan` must match this behaviour.
Owns (create/edit only these): `agent/core/simulate.py`, `agent/core/diff.py`, `agent/core/store.py` (bodies only; keep the frozen signatures and dataclasses), `agent/bridge_client/fake.py`, `tests/unit/test_simulate.py`, `tests/unit/test_diff.py`, `tests/unit/test_store_flow.py`, `tests/unit/test_fake_bridge.py`.
Read-only context: `agent/core/models.py`, `ops.py`, `plan.py`, `hashing.py`, `serde.py`, `agent/bridge_client/protocol.py`, `tests/unit/factories.py`, `tests/unit/test_core_contract.py`, `CLAUDE.md`.
Do not touch: the contract files above (models/ops/plan/hashing/serde/protocol), `tests/unit/factories.py`, anything under `upstream/` or `lua/`. If a contract looks wrong, STOP and report instead of editing it.

## Behaviour
`simulate.apply_ops(snapshot, ops, new_guid=None) -> (Snapshot, refs: dict[str,str])` works on a deep copy, never mutates the input, and raises `PlanError("op i (type): reason")` on the first failing op. `new_guid` is a callable producing GUIDs; the default is a deterministic counter `{FA4E0000-0000-0000-0000-<12 hex>}`.
- Targets are `{GUID}` or `ref:alias` (resolved through refs defined by earlier `insert_track` / `add_region`). Unknown GUID -> error.
- After any `set_folder_depth`, `move_track`, `insert_track`, recompute every track's `parent` from the folder-depth sequence (stack based: depth 1 opens, negative depth closes that many levels).
- `insert_track`: new Track(name, color), folder_depth 0, placed before `before` (None = end). `move_track`: move that one track before `before` (None = end); children are not moved.
- `set_item_lane` requires the item's track to be in `fixed_lanes` mode, else error. `set_lane_name` pads `lane_names` with "" up to the lane. `set_track_lane_mode` only changes the mode.
- `add_region`: Marker with end set, number = max existing + 1. `set_region`: only provided fields change; error if the target is a plain marker or end <= start afterwards.
- `set_ext_state`: stored in `agent_ext` under key `reaper_agent:<key>` (scope track/item/take/project -> Track/Item/Take/ProjectInfo.agent_ext).
- Originals: for ops with `saves_original`, before the first change, write the original value into the object's `agent_ext` ONLY IF that key is absent: keys `reaper_agent:orig_name`, `orig_color` ("#RRGGBB" or ""), `orig_folder_depth`, `orig_lane_mode`, `orig_automation_mode`, `orig_lane`, `orig_prev` (GUID of the track before it, "" if first, for move_track). Regions: project ext `reaper_agent:orig_region:<guid>` = JSON {"name","start","end","color"}. FX params: track ext `reaper_agent:orig_fxparam:<fxguid>:<param>` = repr of the old value.
- FX params and envelope points are not in the Snapshot, so `FakeBridge` keeps them in private dicts: `fx_params[(fx_guid, param)]` (default 0.5) and `env_points[(fx_guid, param)]` (sorted list of EnvPoint). `ensure_fx_envelope` adds an `EnvelopeInfo(kind="fx", name=f"param {n}", fx, param, active=True, visible=True)` if missing and is a no-op otherwise. `insert_envelope_points` and `clear_envelope_range` fail if the envelope does not exist; clear removes points with start <= time < end; `EnvelopeInfo.point_count` is kept in sync. `set_fx_param` fails if the FX GUID is not on that track. Simulation of these private values belongs to `FakeBridge`; `simulate.apply_ops` accepts an optional `hidden` state object for them (design it yourself, keep it simple).
- Snapshot-visible changes only otherwise; never delete tracks, items, takes or markers.

`diff.diff(before, after) -> list[Change]`, ignoring `agent_ext`: tracks added/removed (field "added"/"removed", before/after = name), per-field changes (name, color, folder_depth, parent, lane_mode, lane_names, automation_mode, master_send, sends, fx, envelopes), a single "order" change if the relative order of surviving tracks changed, items (added/removed/track/position/length/lane), takes (added/removed/name/active/offline/source), markers (added/removed/name/position/end/color), project name/path, tempo map. Deterministic order (tracks, items, takes, markers, project, tempo; then guid; then field). Also `format_changes(changes) -> str`, one readable line each.

`FakeBridge(snapshot)` implements `Bridge`: `status()`, `snapshot()` (deep copy), `apply_plan(plan, dry_run=False)` (atomic: on any op error nothing changes, `rolled_back=True`, `ok=False`, `error` names the op; results list the executed ops plus the failing one; `refs` filled with alias -> GUID; dry run simulates on a copy, changes nothing, every OpResult ok with data {"dry_run": True}), `undo()` (a stack, one entry per successful non-dry apply, restores snapshot and hidden state; False when empty), and a test helper `external_edit(fn)` that mutates the snapshot without an undo entry (simulates the user editing in REAPER).

`store.py`: implement `PlanStore`, `build_plan`, `apply_stored_plan`, `undo_last` exactly as documented there. `build_plan` simulates to fill `plan.expected = diff(base, simulated)`. `apply_stored_plan` raises `StalePlanError` (from `agent.core.plan`) if the fresh snapshot hash differs from `plan.base_hash`. After a real, successful apply it diffs pre- vs post-snapshot and compares with `plan.expected` after translating simulated GUIDs of newly created objects to the real GUIDs in `ApplyResult.refs`; differences go in `ApplyOutcome.mismatches`. A real failure returns the failing ApplyResult with no mismatch check and does not set `last_applied`.

## Done when
`uv run pytest tests/unit -q` passes and `uv run ruff check agent tests` and `uv run ruff format --check agent tests` are clean. Tests must cover: every op's simulate behaviour (happy path + at least one failure each), apply -> undo -> snapshot hash identical for every op, atomic rollback on a mid-plan failure, dry run changes nothing, stale-plan refusal after `external_edit`, refs across ops (insert_track then move/set_folder_depth), originals saved only once, diff on each field kind.
Rules: stdlib only, no new dependencies. GUIDs not indices. Never delete user material.
Report (under 150 words): files changed, test result, assumptions, open issues.
